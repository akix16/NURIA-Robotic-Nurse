NURIA: Robotic Nurse with AI Integration

NURIA is a robotic nurse concept designed to support patient monitoring using IoT sensors and AI-based technology. The project focuses on collecting patient health data and presenting it through a monitoring system.

Project Objective

The objective of NURIA is to develop a smart healthcare assistance system capable of monitoring important patient parameters and supporting healthcare professionals with real-time information.

Features

- Real-time patient monitoring

- Health parameter data collection

- Sensor-based monitoring

- Patient monitoring dashboard

- IoT-based communication

- AI integration concept for intelligent healthcare assistance




Technologies and Components

- Python

- ESP32

- MAX301 sensor

- Oximeter sensor

- IoT

- AI concepts

- Data monitoring dashboard


Working Concept

The sensors collect patient health information and transmit the data through the ESP32. The collected information can be processed and displayed through a monitoring dashboard, allowing healthcare personnel to observe patient health parameters.
